# ThemeForge AI Studio

## Resumen Ejecutivo

ThemeForge AI Studio es una plataforma privada impulsada por Inteligencia Artificial orientada a la creación y comercialización de:

- Wallpapers
- Packs de iconos
- Widgets
- Recursos promocionales

---

## Objetivo Principal

Reducir drásticamente el tiempo necesario para crear productos digitales listos para vender en Play Store y App Store.

---

## Tecnologías

### Frontend

- Next.js

- TypeScript
- Tailwind CSS
- Shadcn UI

### Backend

- Supabase

### Inteligencia Artificial

- OpenAI API
