# 14. REGLAS DE NEGOCIO

## Regla 1

Todo recurso debe pertenecer a un proyecto.

## Regla 2

Todo proyecto puede contener múltiples recursos.

## Regla 3

Todo wallpaper debe tener historial de versiones.

## Regla 4

Todo pack de iconos debe estar asociado a un proyecto.

## Regla 5

Toda exportación debe registrarse.
